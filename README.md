# EuropaBuild
### An uncomplicated C++ build system

Free yourself from the clunky and confusing syntax of other build system languages. <br>
EuropaBuild is a meta-build system which makes building simple C++ programs and libraries easier than ever. <br>
Build rules are set up in a simple JSON file. <br>

All you need is
* EuropaBuild itself (the executable)
* A build file: EuropaBuild.json
* [Ninja](https://ninja-build.org/) and a suitable compiler (e.g. [clang](https://clang.llvm.org/))
* Some code to build


### Self-Compiling
EuropaBuild can build itself from source. <br>
No need for another build tool, simply run the **EuropaBuild** executable in the root directory. <br>
Check the included **EuropaBuild.json** to see how the self-build is set up.


### C++ first
The build system itself is written in pure, modern C++. <br>
Support for a wide arrray of languages is _outside_ the scope of this project, <br>
as such, it is mainly intended to build C++ and C code. <br>
That being said, support for the Rust language would be nice. 


### Cross-platform
Building the same program for Windows and GNU/Linux should be effortless. <br>
Cross-compilation (building code to run on another operating system) is currently not supported, but it would be a useful feature to have. <br>

# Examples
The root [self-build file](#self-compiling) (EuropaBuild.json), which is used by the system to build itself, is a good example. <br>
Here is an even simpler one: <br>
```json
[
	{
		"target": "HelloWorld",
		"type": "executable",
		"output path": "build/",
		"sources":
		[
			"HelloWorldSource/"
		],
		"include paths":
		[
		],
		"dependencies":
		[
		]
	}
]
```
This example specifies one target; an application called HelloWorld which has no dependencies. Imagine there is a folder called HelloWorldSource and two files with C++ code: <br>
>HelloWorldSource/HelloWorld.cpp <br>
>HelloWorldSource/HelloWorld.hpp <br>

EuropaBuild recursively finds all source files from each directory in the "sources" array; each target's code must exists in its own distinct directory (or directories).

#### More targets can be added to the JSON array to configure more complicated projects<br>

#### Target types
| Target | Description |
| --- | ------ |
| "executable" | A linked program (.exe) |
| "static library" | A static library (.lib or .a) |
| "dynamic library" | A dynamic library (.DLL) |
| "dependency" | A dependency is linked directly into another target,<br> this is basically the same as specifying more sources into the other target,<br> but could be useful to separate parts or subprojects from each other. |

Dependencies are compiled *before* the targets(s) which depend on them, <br>and are linked against against them once the final target has been compiled.


# Compiler
The [clang](https://clang.llvm.org/) compiler is a good option for C++ development on Windows. EuropaBuild must be able to find it on your system to complete the build.<br>
To check whether clang is installed and present in PATH, run the command `clang++ version`<br>
### Installing clang
Assuming the machine is running Windows, and using the PowerShell terminal: 
1. Install LLVM: `winget install LLVM.LLVM`
2. Add the command to PATH: `[Environment]::SetEnvironmentVariable("Path", [Environment]::GetEnvironmentVariable("Path", "User") + ";C:\Program Files\LLVM\bin", "User")`<br>**Note that you may have to change this command to reflect where LLVM is actually installed on your system.**
1. Open a new PowerShell terminal window and verify with `clang++ version`<br>

# Ninja
### Why Ninja?
Ninja is a very useful tool with an emphasis on speed. <br>It is also written primarily in C++, which makes it suitable for a C++-first ecosystem. <br>Ninja is not a meta-build system, its intended use case is exactly this; i.e. to execute build rules generated by another tool (such as EuropaBuild). <br>
The goal of this project is to simplify and automate builds, not to reinvent the wheel, thus Ninja is required.<br>


# Current status
The project is fully capable of compiling and linking programs, but there may be missing features. <br>
All features and code structure are subject to change.<br> 

Being intentionally simplified, unsupported configurations are bound to exist. <br>
Please submit any feature requests in [Discussions](https://github.com/Europasoft/EuropaBuild/discussions). <br>
